# .vibe: Vibe Your Code

This folder is created by VibeYourFlow for **Nivo OS**. It tells the agents how to work on this
project and how to build and run it.

- `PROJECT.md`: rules and conventions for agents. Edit it freely.
- `preview.json`: toolchain, install, build, test and run command. VibeYourFlow uses it to build,
  test and run the project. Settings changed in the app override it.
- `tests/README.md`: how tests are written and how they run.

Initialize never overwrites these files once they exist.
